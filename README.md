## 📖 游戏简介

末日第七天，你从公寓楼醒来。窗外是丧尸的嘶吼，桌上是最后一瓶矿泉水。

是等死，还是开着房车冲出去？

一款基于 **Phaser 3** 的丧尸末日生存文字冒险游戏。你将在末日中驾驶房车，与伙伴一起穿越丧尸围城，寻找解药，拯救世界。

## 🎮 游戏特色

- ⚔️ **回合制战斗** — 策略性战斗系统，伙伴协同作战
- 👥 **伙伴招募** — 旺仔、冰姐、草哥、老晶、雪盒，每个角色都有独特性格
- 🚐 **房车升级** — 改造你的移动堡垒
- 📖 **分支剧情** — 你的选择决定故事走向
- 🎵 **音效系统** — 沉浸式末日氛围
- 🖼️ **CG 大图** — 关键剧情插图，橙光式体验

## 🛠️ 技术栈

- **引擎：** Phaser 3.60.0
- **语言：** JavaScript (原生)
- **部署：** Vercel

## 📁 项目结构

```
├── index.html              # 入口文件
├── src/
│   ├── main.js             # 游戏配置
│   ├── data/               # 剧情/物品/NPC 数据
│   ├── scenes/             # 场景（战斗/探索/地图/菜单等）
│   ├── systems/            # 系统（对话/背包/存档/音效）
│   ├── entities/           # 实体（NPC/丧尸）
│   └── utils/              # 工具（背景/粒子/UI）
└── assets/
    ├── audio/              # 音效与BGM
    ├── bg/                 # 背景图与CG
    └── characters/         # 角色立绘
```
